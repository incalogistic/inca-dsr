สมุดใช้รถ · งานส่งของ

หจก.อินคา โลจิสติก
INCA คนขับติดตั้งเป็นแอปบนมือถือ

ติดตั้งครั้งเดียว แล้วเปิดจากไอคอนบนหน้าจอหลักได้ทุกวัน เต็มจอ ไม่ต้องจำลิงก์

  1. แตะปุ่มแชร์ ด้านล่างของ Safari
  2. เลื่อนลงแล้วแตะ "เพิ่มไปยังหน้าจอโฮม"
  3. แตะ "เพิ่ม" มุมขวาบน ไอคอน INCA คนขับ จะอยู่บนหน้าจอ
  1. แตะเมนู ⋮ มุมขวาบนของ Chrome
  2. แตะ "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"

บน iPhone ให้เปิดลิงก์นี้ด้วย Safari จึงจะติดตั้งได้

แอดมิน: เปิดไฟล์ config.js แล้ววางลิงก์ Web app (ลงท้ายด้วย /exec) จาก Apps Script → Deploy → Manage deployments
